# chaos CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a `chaos` CLI (Typer) that injects and reverts 5 fault
scenarios against Online Boutique on the local kind cluster, each with a
YAML-recorded ground truth, backed by a mocked-k8s-client test suite.

**Architecture:** A `K8sClient` wrapper isolates the real
`kubernetes.client` SDK behind a small interface; a `Scenario` ABC gives
each of the 5 fault types `inject`/`revert`/`ground_truth`; a local JSON
state file tracks the one allowed active injection and the snapshot
needed to revert it exactly; a Typer app wires `list`/`inject`/`revert`/
`status` together.

**Tech Stack:** Python 3.12, Typer, the official `kubernetes` Python
client, PyYAML, pytest, uv workspace.

**Spec:** `docs/superpowers/specs/2026-10-13-chaos-cli-design.md`

## Global Constraints

- `chaos/` is a uv workspace member (`triage-chaos`), added to root
  `pyproject.toml`'s `[tool.uv.workspace] members`.
- Namespace is always `boutique`; valid service names are exactly the 12
  Online Boutique deployments: adservice, cartservice, checkoutservice,
  currencyservice, emailservice, frontend, loadgenerator, paymentservice,
  productcatalogservice, recommendationservice, redis-cart,
  shippingservice.
- Only one injection may be active at a time; `inject` refuses if a state
  file already exists, `revert` errors if none exists.
- `revert` must restore the exact prior state (snapshot taken before
  patching, in every scenario).
- Scenario classes never import `kubernetes.client` directly — only
  through `K8sClient`, so tests use a fake implementing the same
  interface, never a real cluster.
- Ground truth (`root_cause_label`, `expected_fix`, fixed/default params)
  lives in YAML under `chaos/src/chaos/scenarios/definitions/`;
  `affected_service` is computed at runtime, not stored in YAML.
- Type hints everywhere; this workspace member must pass `mypy --strict`
  and `ruff check` (root `pyproject.toml` config applies repo-wide).
- Tests: `pytest`, using a fake `K8sClient`, never a real cluster.

## Review Focus

- Unknown scenario name passed to `chaos inject`/`chaos revert` — should
  error with the valid scenario list, not crash with a `KeyError`.
- Unknown or missing `--service` for a scenario that requires one
  (`oom`, `bad_deploy`, `cpu_throttle`) — should error listing the 12
  valid service names, not send a malformed patch to the cluster.
- `--service` passed to a fixed-target scenario (`crash_loop`,
  `slow_redis`) — should be rejected or ignored explicitly, not silently
  patch the wrong deployment.
- `chaos revert` called with a `scenario` argument that doesn't match the
  currently active one — should error rather than silently reverting the
  wrong scenario's logic against the active snapshot.
- Corrupt or partially-written state file (e.g. process killed mid-write)
  — `chaos status`/`revert` should fail with a clear message, not a raw
  `json.JSONDecodeError` traceback.

    - `get_deployment(self, name: str) -> dict[str, Any]` — returns the
      deployment's pod spec as a plain dict: `{"containers": [{"name": str, "image": str, "command": list[str] | None, "env": list[dict[str, str]], "resources": dict[str, Any]}, ...]}`

      list (converted to the SDK's expected shape internally).
    - `exec_in_pod(self, pod_label_selector: str, container: str, command: list[str]) -> str`
      — finds the first running pod matching the label selector, execs
      `command` in `container`, returns stdout.
  - `class FakeK8sClient` in `chaos/tests/fake_k8s.py` implementing the
    same four methods against an in-memory dict, for use by every
    scenario test and the CLI tests.

Rationale for the plain-dict interface: scenario code never touches
`kubernetes.client.V1Deployment`/`V1Container` objects directly, so fakes
in tests don't need the real SDK installed to run, and scenario diffs
are easy to read/snapshot in tests.

```python
from typing import Any

from kubernetes import client, config


class K8sClient:
    def __init__(self, namespace: str = "boutique") -> None:
        config.load_kube_config()
        self._apps = client.AppsV1Api()
        self._core = client.CoreV1Api()
        self.namespace = namespace

    def get_deployment(self, name: str) -> dict[str, Any]:
        deployment = self._apps.read_namespaced_deployment(name=name, namespace=self.namespace)
        containers = deployment.spec.template.spec.containers
        return {"containers": [self._container_to_dict(c) for c in containers]}

    def patch_containers(self, name: str, containers: list[dict[str, Any]]) -> None:
        body = {
            "spec": {
                "template": {
                    "spec": {
                        "containers": [self._dict_to_container_patch(c) for c in containers]
                    }
                }
            }
        }
        self._apps.patch_namespaced_deployment(name=name, namespace=self.namespace, body=body)

    def exec_in_pod(self, pod_label_selector: str, container: str, command: list[str]) -> str:
        from kubernetes.stream import stream

        pods = self._core.list_namespaced_pod(
            namespace=self.namespace, label_selector=pod_label_selector
        )
        pod_name = pods.items[0].metadata.name
        result = stream(
            self._core.connect_get_namespaced_pod_exec,
            name=pod_name,
            namespace=self.namespace,
            container=container,
            command=command,
            stderr=True,
            stdin=False,
            stdout=True,
            tty=False,
        )
        return str(result)

    @staticmethod
    def _container_to_dict(c: Any) -> dict[str, Any]:
        env = [{"name": e.name, "value": e.value} for e in (c.env or [])]
        resources = {
            "limits": c.resources.limits if c.resources else None,
            "requests": c.resources.requests if c.resources else None,
        }
        return {
            "name": c.name,
            "image": c.image,
            "command": c.command,
            "env": env,
            "resources": resources,
        }

    @staticmethod
    def _dict_to_container_patch(c: dict[str, Any]) -> dict[str, Any]:
        patch: dict[str, Any] = {"name": c["name"], "image": c["image"]}
        if c.get("command") is not None:
            patch["command"] = c["command"]
        if c.get("env") is not None:
            patch["env"] = c["env"]
        if c.get("resources") is not None:
            patch["resources"] = c["resources"]
        return patch
```

Create `chaos/src/chaos/state.py`:

```python
import json
from dataclasses import asdict, dataclass
from pathlib import Path
from typing import Any


class StateCorruptError(Exception):
    pass


@dataclass
class ActiveInjection:
    scenario: str
    service: str
    namespace: str
    injected_at: str
    saved_state: dict[str, Any]


_REQUIRED_FIELDS = {"scenario", "service", "namespace", "injected_at", "saved_state"}


class StateStore:
    def __init__(self, path: Path) -> None:
        self._path = path

    def load(self) -> ActiveInjection | None:
        if not self._path.exists():
            return None
        try:
            raw = json.loads(self._path.read_text())
        except json.JSONDecodeError as exc:
            raise StateCorruptError(f"{self._path} is not valid JSON") from exc
        if not isinstance(raw, dict) or not _REQUIRED_FIELDS.issubset(raw.keys()):
            raise StateCorruptError(f"{self._path} is missing required fields")
        return ActiveInjection(**raw)

    def save(self, injection: ActiveInjection) -> None:
        self._path.parent.mkdir(parents=True, exist_ok=True)
        self._path.write_text(json.dumps(asdict(injection), indent=2))

    def clear(self) -> None:
        self._path.unlink(missing_ok=True)
```

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from pathlib import Path
from typing import Any, ClassVar

import yaml

_DEFINITIONS_DIR = Path(__file__).parent / "definitions"


@dataclass
class ScenarioDefinition:
    name: str
    description: str
    root_cause_label: str
    expected_fix: str
    fixed_service: str | None
    default_params: dict[str, Any]


def load_definition(name: str) -> ScenarioDefinition:
    path = _DEFINITIONS_DIR / f"{name}.yaml"
    if not path.exists():
        raise FileNotFoundError(f"no scenario definition for {name!r} at {path}")
    raw = yaml.safe_load(path.read_text())
    return ScenarioDefinition(**raw)


class Scenario(ABC):
    name: ClassVar[str]
    requires_service: ClassVar[bool]

    @abstractmethod
    def inject(self, k8s: Any, service: str) -> dict[str, Any]:
        """Apply the fault, return a JSON-serializable snapshot for revert()."""

    @abstractmethod
    def revert(self, k8s: Any, service: str, saved_state: dict[str, Any]) -> None:
        """Restore exactly what inject() overwrote."""

    def ground_truth(self, service: str) -> dict[str, Any]:
        definition = load_definition(self.name)
        affected_service = definition.fixed_service or service
        return {
            "root_cause_label": definition.root_cause_label,
            "affected_service": affected_service,
            "expected_fix": definition.expected_fix,
        }
```

Note: `_DEFINITIONS_DIR` is module-level so tests can monkeypatch it
directly via `monkeypatch.setattr("chaos.scenarios.base._DEFINITIONS_DIR", ...)`.

```python
_TARGET_DEPLOYMENT = "redis-cart"
_CONTAINER_NAME = "redis-cart"
_LABEL_SELECTOR = "app=redis-cart"


class SlowRedisScenario(Scenario):
    name: ClassVar[str] = "slow_redis"
    requires_service: ClassVar[bool] = False

    def inject(self, k8s: Any, service: str) -> dict[str, Any]:
        definition = load_definition(self.name)
        internal_port = definition.default_params["redis_internal_port"]
        toxiproxy_image = definition.default_params["toxiproxy_image"]
        latency_ms = definition.default_params["latency_ms"]

        deployment = k8s.get_deployment(_TARGET_DEPLOYMENT)
        prior_containers = deployment["containers"]

        redis_container = dict(next(c for c in prior_containers if c["name"] == _CONTAINER_NAME))
        redis_container["command"] = ["redis-server", "--port", internal_port]
        toxiproxy_container = {
            "name": "toxiproxy",
            "image": toxiproxy_image,
            "command": None,
            "env": [],
            "resources": None,
        }

        k8s.patch_containers(_TARGET_DEPLOYMENT, [redis_container, toxiproxy_container])

        k8s.exec_in_pod(
            _LABEL_SELECTOR,
            "toxiproxy",
            [
                "toxiproxy-cli",
                "create",
                "redis",
                "-l",
                "0.0.0.0:6379",
                "-u",
                f"127.0.0.1:{internal_port}",
            ],
        )
        k8s.exec_in_pod(
            _LABEL_SELECTOR,
            "toxiproxy",
            ["toxiproxy-cli", "toxic", "add", "redis", "-t", "latency", "-a", f"latency={latency_ms}"],
        )

        return {"containers": prior_containers}

    def revert(self, k8s: Any, service: str, saved_state: dict[str, Any]) -> None:
        k8s.patch_containers(_TARGET_DEPLOYMENT, saved_state["containers"])
```

```python
import sys
from datetime import UTC, datetime
from pathlib import Path
from typing import Any

import typer

from chaos.scenarios.bad_deploy import BadDeployScenario
from chaos.scenarios.base import Scenario, load_definition
from chaos.scenarios.crash_loop import CrashLoopScenario
from chaos.scenarios.cpu_throttle import CpuThrottleScenario
from chaos.scenarios.oom import OomScenario
from chaos.scenarios.slow_redis import SlowRedisScenario
from chaos.state import ActiveInjection, StateCorruptError, StateStore

app = typer.Typer()

NAMESPACE = "boutique"

SERVICES = [
    "adservice",
    "cartservice",
    "checkoutservice",
    "currencyservice",
    "emailservice",
    "frontend",
    "loadgenerator",
    "paymentservice",
    "productcatalogservice",
    "recommendationservice",
    "redis-cart",
    "shippingservice",
]

_SCENARIOS: dict[str, type[Scenario]] = {
    "crash_loop": CrashLoopScenario,
    "oom": OomScenario,
    "bad_deploy": BadDeployScenario,
    "cpu_throttle": CpuThrottleScenario,
    "slow_redis": SlowRedisScenario,
}


def _state_path() -> Path:
    return Path("chaos/.state/active.json")


def _build_k8s_client() -> Any:
    from chaos.k8s import K8sClient

    return K8sClient(namespace=NAMESPACE)


def _fail(message: str) -> None:
    typer.echo(message)
    raise typer.Exit(code=1)


def _resolve_scenario(name: str) -> type[Scenario]:
    scenario_cls = _SCENARIOS.get(name)
    if scenario_cls is None:
        _fail(f"unknown scenario {name!r}. Valid scenarios: {', '.join(sorted(_SCENARIOS))}")
        raise AssertionError("unreachable")  # for mypy; _fail always raises
    return scenario_cls


@app.command("list")
def list_scenarios() -> None:
    for name in sorted(_SCENARIOS):
        definition = load_definition(name)
        typer.echo(f"{name}: {definition.description}")


@app.command("inject")
def inject(
    scenario: str,
    service: str = typer.Option(None, "--service"),
) -> None:
    store = StateStore(_state_path())
    try:
        active = store.load()
    except StateCorruptError as exc:
        _fail(f"state file is corrupt: {exc}")
        return

    if active is not None:
        _fail(
            f"scenario {active.scenario!r} is already active on {active.service!r}. "
            "Run `chaos revert` first."
        )
        return

    scenario_cls = _resolve_scenario(scenario)
    scenario_instance = scenario_cls()

    if scenario_instance.requires_service:
        if service is None:
            _fail(
                f"scenario {scenario!r} requires --service. Valid services: {', '.join(SERVICES)}"
            )
            return
        if service not in SERVICES:
            _fail(f"unknown service {service!r}. Valid services: {', '.join(SERVICES)}")
            return
        target_service = service
    else:
        definition = load_definition(scenario)
        if service is not None and service != definition.fixed_service:
            _fail(
                f"scenario {scenario!r} has a fixed target "
                f"({definition.fixed_service!r}); --service may not be overridden"
            )
            return
        target_service = definition.fixed_service or ""

    k8s = _build_k8s_client()
    saved_state = scenario_instance.inject(k8s, target_service)

    store.save(
        ActiveInjection(
            scenario=scenario,
            service=target_service,
            namespace=NAMESPACE,
            injected_at=datetime.now(UTC).isoformat(),
            saved_state=saved_state,
        )
    )

    ground_truth = scenario_instance.ground_truth(target_service)
    typer.echo(f"injected {scenario!r} on {target_service!r}")
    typer.echo(f"ground truth: {ground_truth}")


@app.command("revert")
def revert(scenario: str = typer.Argument(None)) -> None:
    store = StateStore(_state_path())
    try:
        active = store.load()
    except StateCorruptError as exc:
        _fail(f"state file is corrupt: {exc}")
        return

    if active is None:
        _fail("no active injection to revert")
        return

    if scenario is not None and scenario != active.scenario:
        _fail(f"active injection is {active.scenario!r}, not {scenario!r}")
        return

    scenario_cls = _resolve_scenario(active.scenario)
    scenario_instance = scenario_cls()

    k8s = _build_k8s_client()
    scenario_instance.revert(k8s, active.service, active.saved_state)

    store.clear()
    typer.echo(f"reverted {active.scenario!r} on {active.service!r}")


@app.command("status")
def status() -> None:
    store = StateStore(_state_path())
    try:
        active = store.load()
    except StateCorruptError as exc:
        _fail(f"state file is corrupt: {exc}")
        return

    if active is None:
        typer.echo("no active injection")
        return

    typer.echo(
        f"active: scenario={active.scenario} service={active.service} "
        f"injected_at={active.injected_at}"
    )


if __name__ == "__main__":
    app()
```

Note on `_fail`: it's typed `-> None` but always raises; call sites use
`return` immediately after for control-flow clarity under `mypy --strict`
(a bare `_fail(...)` followed by code that assumes early-exit would
otherwise need a `NoReturn` annotation — acceptable either way, but the
`return` pattern above avoids introducing `NoReturn` just for this).
