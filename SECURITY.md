# Security

This is a portfolio project with no formal support SLA. If you find a
security issue, please open a GitHub issue (or a private security
advisory via GitHub's "Report a vulnerability" feature if the issue is
sensitive) rather than a public pull request with exploit details.

See `CLAUDE.md`'s Safety rules section for the project's existing
safety/RBAC boundaries (read-only agent, approval-gated executor,
audit logging).
